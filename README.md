# Vibe Retro Studio

Make games for the ModRetro Chromatic by describing them. Studio builds what you ask for, shows it on an exact screen next to your agent, and keeps every version in your own repo on GitHub.

**[Download for Windows](https://github.com/AivionStudiosPlayground/vibe-retro-studio/releases/latest/download/Vibe-Retro-Studio-Setup.exe)** · Beta · Free · Windows 10 and 11

More about Studio: [viberetrogames.com/studio](https://viberetrogames.com/studio/)

## Installing

1. Download `Vibe-Retro-Studio-Setup.exe` and open it.
2. Windows may say it protected your PC, because the app is not signed yet. Click **More info**, then **Run anyway**.
3. Click **Install**. The installer also sets up Git, GitHub CLI and the agents you tick (Claude Code, Codex). What is there already stays as it is.
4. Studio starts by itself. Sign in to your agent there, once, and start your first game.

There is no account with Vibe Retro and no licence key. Your agents work on your own Claude or ChatGPT plan.

## Updates

Studio looks for a new version by itself. When one is ready, a button in the top bar restarts Studio with it.
